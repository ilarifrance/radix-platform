## Current scope

Finish the Command Center and RADIX → project → attributed workflow/task navigation first. PED, PM, CRM and DOC are future specialized workspaces. Their entry points must state that they are not available yet. Preserve project context in future module routes; do not create fake tool screens or agents to fill the network.

## Verification limits

The browser refused access to the Vercel Preview on 9 October because permission had been denied. Logic tests do not establish visual fidelity, responsive quality, pointer behavior or screenshot equivalence. These remain mandatory before accepting the implementation.

The v3.7 workspace reads the selected project from shared server state. A query parameter alone does not change that selection. The current constraints prohibit editing index.html and shared database state, so the handoff needs a separately agreed integration point; no selection guarantee is currently claimed.
